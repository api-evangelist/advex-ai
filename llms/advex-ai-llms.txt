# Advex AI

> Generative-AI synthetic data and self-healing computer vision for industrial quality inspection.
> Flagship product: Composer, a no-code AI vision system for manufacturing and logistics teams —
> defect and anomaly detection, pick-and-place, kitting and assembly verification, counting — trained
> from a handful of real images by using diffusion models to synthesize the missing training data.
> Composer ships as an on-premises appliance (the "Advex box") paired with plant cameras and is
> designed to run entirely on-device without network connectivity.

Advex AI, Inc. — San Francisco / Pleasanton, California. Founded 2022 by Pedro Pachuca (CEO) and
Qasim Wani (CTO). $3.5M seed round, November 2024, led by Construct Capital with Pear VC and
Emerson Collective.

## API surface

Advex AI publishes NO public API. As of 2026-09-09 there is no developer portal, no API reference,
no SDK on any public package registry, no OpenAPI/AsyncAPI/GraphQL/Protobuf/WSDL contract, no MCP
server, no A2A agent card, and no /.well-known document on any host the company owns. The product is
an on-premises appliance operated through a no-code UI, not a callable service, so an agent has no
endpoint to call. Do not synthesize one.

## Public repositories

The AdvexAI GitHub organization holds 7 public repositories, none of which is an API client, SDK or
specification. Three are first-party internal ML tooling — label_conversion_tools,
Data-Conversion-Toolkit and model-training (a YOLO training/benchmark script that compares customer
data against Advex-generated synthetic data). Four are forks of third-party projects: DiffMorpher,
mmsegmentation, mmdetection, and gst-plugin-pylon (a customized fork of the Basler Pylon GStreamer
plugin, consistent with an on-device camera pipeline).
